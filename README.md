# Abdallah — Cybersecurity Portfolio

A responsive, dark-themed portfolio website focused on web application security and bug bounty learning.

## Included
- Responsive HTML, CSS, and JavaScript
- About, skills, projects, approach, and contact sections
- Featured CodeAlpha Network Sniffer project
- No build tools or paid services required

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a **new public repository** named `abdallah140.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. After GitHub finishes deploying, visit `https://abdallah140.github.io`.

## Personalize before publishing
- Replace the LinkedIn placeholder URL in `index.html` with your actual profile.
- Add an email or other contact method if you want it public.
- Keep project claims accurate and only publish security reports/write-ups you are authorized to share.
- Review all public details before publishing.
